# RideConect X Design

RideConnectX companion app UI — built with React, Vite, Tailwind CSS v4, and Framer Motion.

## Branch: `rideconect-x-design`

This branch contains the full production-ready UI design for the RideConnectX Android companion app.

## Stack
- React 18
- Vite 6
- Tailwind CSS v4
- Motion (Framer Motion)
- Radix UI primitives
- Lucide React icons

## Run locally
```bash
npm install
npm run build
```
